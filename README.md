# Student Performance Analysis

## Project Overview
This project analyzes student academic performance
using Python and Excel.

## Technologies Used
- Python
- Pandas
- NumPy
- Matplotlib
- Seaborn
- Microsoft Excel
- Jupyter Notebook

## Dataset
The dataset contains 20 students with marks in:
- Maths
- Science
- English

## Analysis Performed
1. Total Marks Calculation
2. Average Marks Calculation
3. Topper Identification
4. Lowest Performer Identification
5. Pass/Fail Analysis
6. Subject-wise Performance
7. Data Visualization

## Results
- Total Students: 20
- Pass Students: 19
- Fail Students: 1
- Pass Percentage: 95%

## Visualizations
Three charts were created:
- Subject-wise Average Marks
- Student Performance
- Pass vs Fail Analysis
